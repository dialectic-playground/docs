# Tutorials

Tutorials are **lessons**. A tutorial takes a newcomer by the hand through a series of
steps toward a meaningful, working result. Its job is to help you *learn*. Being complete
is not the goal.

!!! abstract "What belongs here"
    - A single, reliable path from a known starting point to a visible result.
    - Concrete actions with an immediately visible outcome at every step.
    - Only as much explanation as you need to keep going, with links to
      [Explanation](../explanation/index.md) for the rest.
    - Nothing optional. No choices, alternatives, or detours.

!!! failure "What does not belong here"
    - Instructions for a task the reader already understands → [How-to guides](../how-to/index.md)
    - Lists of options, flags, or file formats → [Reference](../reference/index.md)
    - Design rationale and background → [Explanation](../explanation/index.md)
