# Dialectic Playground Docs

![dialectic playground / docs](assets/brand/logo.svg#only-light){ width="360" }
![dialectic playground / docs](assets/brand/logo-dark.svg#only-dark){ width="360" }

**Dialectic Playground** is a polyglot workshop for exploring language design,
implementations, and shared tooling. The same ideas are built side by side in different
programming languages, each in its own repository, against shared specifications.

This site is the shared documentation hub. It is organized with
[Diátaxis](https://diataxis.fr), so every page belongs to one of four kinds, each serving a
different need:

<div class="grid cards dp-quadrants" markdown>

-   :material-school-outline:{ .lg .middle } **[Tutorials](tutorials/index.md)**

    ---

    *Learning-oriented.* Guided lessons that take you from nothing to a working result.
    Start here if you are new.

-   :material-directions:{ .lg .middle } **[How-to guides](how-to/index.md)**

    ---

    *Task-oriented.* Practical steps to get a specific job done, for when you already know
    what you want.

-   :material-book-open-variant:{ .lg .middle } **[Reference](reference/index.md)**

    ---

    *Information-oriented.* Accurate, complete descriptions of the repositories, the
    curriculum, and the language implementations.

-   :material-lightbulb-on-outline:{ .lg .middle } **[Explanation](explanation/index.md)**

    ---

    *Understanding-oriented.* Background, context, and the reasoning behind the project's
    design decisions.

</div>
