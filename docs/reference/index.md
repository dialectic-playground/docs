# Reference

Reference pages are **descriptions**. They state the facts about the machinery accurately,
completely, and neutrally, organized to mirror the structure of the thing they describe.
Readers consult reference material while they work. They don't read it from start to finish.

<!-- prettier-ignore-start -->
!!! abstract "What belongs here"
    - Austere, factual descriptions: repositories, projects, tools, options, formats, statuses.
    - A consistent structure, so the same kind of fact is always in the same place.
    - Short usage examples that illustrate, never teach.
<!-- prettier-ignore-end -->

<!-- prettier-ignore-start -->
!!! failure "What does not belong here"
    - Guided learning → [Tutorials](../tutorials/index.md)
    - Steps to achieve a goal → [How-to guides](../how-to/index.md)
    - Opinions, history, and rationale → [Explanation](../explanation/index.md)
<!-- prettier-ignore-end -->
