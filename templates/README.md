# Page templates

One skeleton per Diátaxis page type. Copy the matching file into the right quadrant under
`docs/`, replace every _italic prompt_, and delete the guidance block. See
[Contribute documentation](../docs/how-to/contribute-documentation.md).

| Template                           | Use for                            | Destination         |
| :--------------------------------- | :--------------------------------- | :------------------ |
| [`tutorial.md`](tutorial.md)       | A lesson that teaches by doing     | `docs/tutorials/`   |
| [`how-to.md`](how-to.md)           | Steps to reach a specific goal     | `docs/how-to/`      |
| [`reference.md`](reference.md)     | A factual description of something | `docs/reference/`   |
| [`explanation.md`](explanation.md) | Context, background, and rationale | `docs/explanation/` |
